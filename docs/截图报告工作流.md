# 截图报告处理工作流（SOP + 唯一入口）

> **口径已统一**：本文件的流程已并入 `docs/导入工作流.md`（唯一入口，含判重四层与原件 Blob）。两者冲突时以该文件为准。

> 适用：手机截图 / 微信导出的**检验单、影像报告详情页**图片 → 结构化报告进 MedBrief（带原件）。
> 定稿 2026-11-13（样本：58 张截图 → 47 份报告 + 4 张孤页）。**流程固定，版式靠适配器长**。

## 一、一条命令

```bash
# dry-run（只打印计划，不写文件、不入库）
node tools/workflow-screenshots.mjs --src "<微信 RWTemp 月目录>" --src "~/Desktop/122"

# 落盘 + 入库（原件进 SQLite blobs）
node tools/workflow-screenshots.mjs --src ... --src ... --apply --import
```

七步流水线（每步都有打印，失败不静默）：

| # | 步骤 | 判据 / 实现 |
|---|---|---|
| 1 | 发现 | 递归 ≤2 层；**按魔数**识别 jpg/png/gif/webp/pdf；跳过 `_t` 缩略图、<20KB、`07085632` 头的微信 V2 加密 `.dat` |
| 2 | OCR | `POST /api/intake/ocr`（8008 视觉网关），并发默认 6；结果按「路径+大小+mtime」缓存到 `data/tmp/wf-ocr-cache.json`，重跑不烧 OCR |
| 3 | 身份 | 单号 `报告单号/条码号/报告编号/MAX…`；日期 `报告时间/报告日期/送检日期/采集时间`；医院 `就诊医院/送检单位`；项目 `项目名称` |
| 4 | 查重 | ① `sha256` 字节级 ② 同单号+同报告时间（留字节更大者）。**不用 dHash**（文本截图上不同报告距离可为 0） |
| 5 | 跨屏配对 | 三条接受路径：① **血常规算术铁证** `白细胞计数 × 淋巴细胞百分比 ≈ 淋巴细胞计数` ② 重叠 ≥2 行且 b 大多是 a 里没有的行 ③ 页1 末行 == 页2 首行（严格邻接）。配对后**贪心独占分配**，一份页1 只配一份页2 |
| 6 | 分类 | 化验单屏 / 影像全文（`textOnly`）/ 拼接 / 孤页；**兜底：OCR 出空的一律进孤页**，绝不静默丢 |
| 7 | 产出入库 | `批A/`（化验）`批B/`（影像）`拼接/`（含 `源页/`）`孤页/` `文字识别/` + `manifest.json` → `tools/import-inbox.mjs` |

## 二、为什么是这些判据（都是实测踩坑）

1. **微信图片有两种**：`temp/RWTemp/<YYYY-MM>/` 是**明文** JPEG（按浏览时间落盘）；`msg/attach/*/Img/*.dat` 若头是 `07 08 56 32 08 07` 则是 V2 加密容器（XOR/AES 单字节试探全部失败）→ 只收明文。
2. **同一页会存在多份副本**：`_t` 缩略图、`_M/_h` 变体、不同导出格式（png 431KB vs jpg 271KB）。字节级 sha256 只能抓一部分，必须叠加「单号+报告时间」。
3. **dHash 在文本截图上不可用**：9×8 灰度只记住「白底黑字两栏」——`凝血 07-26` 与 `凝血 08-04` 汉明距离 **0**，14 张不同影像报告会被聚成一簇。
4. **不能用文本相似度配对**：同版式不同日期的血常规文字几乎一样（实测把 07-14 的页 2 配给了 07-18）。必须用「行名+数值」的连续性 + 算术校验。
5. **拼接图不能当数据源**：整图重跑 OCR 会丢行（实测 `20260701G0000002` 丢 2 行、`20260701G0000003` 丢 2 行）→ rows 用两页各自 OCR 的并集，拼接图只作完整原件。

## 三、已知边界

- 微信 V2 加密 `.dat`（2026-11 之后的大部分原图）解不出 → 需要用户从微信「查看原图」导出到 `temp/RWTemp` 或拖进任意目录。
- 影像报告详情页（`检查报告详情`）是**全文型**：`rows=[]`、全文进 `report.text`，卡片不参与数值趋势。
- OCR 噪声（`⑦/◎/个(↑)`、单位 `μmol/L→wmol/L`、`10^9/L→10~9/L`）在解析器里做清洗，每行都留 `rawSnippet` 原文片段。
- 抬头被裁掉的「孤页」不自动猜日期：进 `孤页/`，由人给日期后再走同一工作流。

## 四、与其它入口的关系

| 入口 | 用途 |
|---|---|
| `tools/workflow-screenshots.mjs` | **截图/图片批量**（本工作流，唯一入口） |
| `tools/import-inbox.mjs` | 按 manifest 入库（带原件 blob），供工作流调用，也可单独跑 |
| `tools/import-report.mjs` | 旧的「单份/目录」CLI，仍可用于 PDF；但 rows 走项目自带 `parseLabRows`（会丢定性行），**截图批不要用它** |
| `tools/repair-import.mjs` | 幂等修数：按 manifest 覆盖 rows + 按 sha8 回填 `sourceBlobs` 关联 |
