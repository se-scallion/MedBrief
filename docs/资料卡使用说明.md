# 问诊资料卡使用说明（给患者家属看）

您好。这份说明是给陪同就诊的家属看的，尽量不用医院里的专业说法。文中出现的人名、医院名和数值都是虚构示例，用来讲清楚按钮在哪里、点一下会发生什么，不对应任何真实病历。

## 一、资料卡是什么，打印出来给谁看

资料卡是把家里已经导入的一张张报告，整理成一份给门诊医生快速看的纸面材料。医生时间有限，翻一摞原件容易漏掉关键变化，资料卡把"最近一次的结果、全部项目、几次结果的变化"按固定顺序排好，打印出来是固定三页 A4（A4 就是常见的复印纸大小）。

三页各有分工：第 1 页是速览，抬头写姓名、诊断等基本信息，接着是疾病标签与安全基线、核心异常项、家属三问，医生先看这一页就能抓住重点；第 2 页是分类明细，把全部指标按临床大类分组列出，方便逐项核对；第 3 页是关键趋势，用曲线画出同一项目多次检查的变化，只有同一项目出现过两次以上才会画。

需要先解释两个词：**参考区间** —— 报告上给出的"正常范围"，比如某项写着一个下限和一个上限，超出就可能被标成偏高或偏低；**危急值** —— 明显超出安全范围、需要尽快让医生知道的结果，卡上会用红色或带"危急"字样的标记提示，但它只是提示，不是诊断。

这份纸面材料是给医生看的辅助整理，不是新的检查报告，也不会替医生下判断。若某页出现"未录入 / 待核"，意思是家里还没提供这项资料或需要再核对原件，系统不会替您猜一个数字填上去。

## 二、怎么打开资料卡（电脑和手机）

电脑上打开后，左侧有一列菜单，分两组：「资料」（资料录入 / 报告库 / 资料卡 / 病历交换包）和「出诊」（出诊监控 / 挂号与预约 / 114 会话），点「资料卡」进入。

手机屏幕窄，**左侧那列菜单会收起来**，改由左上角的「☰」按钮打开。「☰」是三条横线组成的图标，点它会出现「导航菜单」抽屉（从侧边滑出的一层菜单），里面同样是那两组、共 7 项：资料录入、报告库、资料卡、病历交换包、出诊监控、挂号与预约、114 会话。点「资料卡」就进入，抽屉会自己收起；想换别的页面，再点一次「☰」即可。

进页面后，右上角有两个按钮：「编辑档案与三问」用来补填档案信息和您想问医生的问题；「打印预览 / 存 PDF」用来出纸或存成文件（见后文「怎么打印或存成 PDF」一节）。

## 三、三个视图怎么用

中间有三个标签页，点标签名即可切换。手机上看长表格时往下滚动，**那一排标签会吸在屏幕顶部**，随时能切，不用一路滚回页首。

1. **临床指标总览**：这里把最近一次的结果按项目列成表格。点任意一行，会弹出「原件溯源」窗口：左边是这一项对应的**原件**（原件就是当初导入的原始报告照片或 PDF 文件，只读、不能改），右边是这项指标历次检查的记录和同一份报告里的其他指标。窗口里可以用「＋ 放大」「− 缩小」「适应宽度」「适应高度」看清楚小字，PDF 还能点「上一页」「下一页」翻页；看完点「关闭」。
2. **动态趋势看板**：勾选想看的项目（有两次以上记录的项目才能画曲线），曲线上的每个圆点代表一次检查；点圆点同样会打开那一份原件。这里不做不同项目的强行对比，单位不一致的项目不会硬拼成一条线，避免看起来像"假趋势"。需要快速操作时，卡片右上有「恢复默认 8 项」「全选」「清空」。
3. **全病程原件轴**：按日期从新到旧列出**全部已导入的报告**，包括影像、骨穿、基因这类不进打印版的资料。点任意一条就打开原件。上方可以按类型筛选，也可以输入关键词搜索；同一天有多份报告时，条目里会带类型、单号和时间，方便区分。

**MICM 分型** —— 白血病确诊时要做的一组检查（形态、免疫、细胞遗传、分子），报告里常写成一长串缩写；这类报告即使不在打印的三页里，也能在「全病程原件轴」里按日期找回来。

## 四、怎么打印或存成 PDF

**PDF** —— 一种在任何设备上打开都不容易跑版的文件格式，适合发给医生或自己留存。

1. 在资料卡页右上角点「打印预览 / 存 PDF」，会弹出「打印预览（3 页 A4）」窗口，标题旁会显示「已脱敏」或「未脱敏」。
2. 确认三页内容无误后，点窗口右下角的「立即打印 / 存为 PDF」。在弹出的系统对话框里，选打印机就出纸，选存成 PDF 就得到一份电子文件。
3. 手机上如果弹窗里排版不好操作，点同一窗口的「新窗口打开纯净打印页」，会另开一个只含三页内容的干净页面；该页顶部也有「打印 / 存 PDF」按钮。手机浏览器通常叫"分享 → 打印"或"存储为文件"，按屏幕提示选即可。
4. 打印固定是三页 A4，不会因为内容多少自动变成很多页；看完点「关闭」回到资料卡。

小提醒：给医生看时建议保持「未脱敏」，姓名完整更方便核对；若要发给别人或拍照发群里，可先打开弹窗左下角的「脱敏」开关，再打印。

## 五、「修正数值」怎么用，为什么要整行核对

在「原件溯源」窗口右侧，有一处「修正数值」按钮（按钮文字后面还跟着一串括号里的技术备注，那是给维护人员看的记录标记，家属直接忽略即可）。它用于**录入或识别写错**的情况，例如原件上明明写着某个单位和参考区间，系统却读成了别的文字。点开后会出现「项目」「数值」「单位」「参考」四个输入框，旁边有「保存」和「取消」，还有一行小字「不提供删除」。

**单位** —— 数值后面那个说明量纲的词，比如某项结果写"某某数值 某某单位"，没有单位数字就没有意义。**参考区间**前面已解释，是判断偏高偏低的尺子。

这里最关键的一句话：点「保存」时，系统会把**名称、数值、单位、参考区间四项一起写回**，不是只改您看见的那个数字。因为资料是从原件一行行整理出来的，只提交一个数字，那一行的其余内容会被当成"没提供"，尤其是参考区间可能就此空掉。举个反例：假如只把数值改对、却没把参考区间一起提交，保存后这一行的尺子会**永久丢失**，以后医生再看就分不清偏高还是正常，只能回头翻原件重新核对。所以请把四个框逐项对着原件看完，确认整行都一致，再点「保存」；没把握就点「取消」，原件始终只读、不会被改。旧值会留一条修改记录，方便日后回查。

另外，应用**不提供删除报告的按钮**（在修正区域也能看到「不提供删除」字样）。这是刻意的：病历资料宁可留着让医生判断，也不该在手机上一点就消失。

## 六、隐私：哪些信息不存，脱敏改了什么

系统只整理您已经导入的报告，不收集身份证号、手机号、住址，也不要求填写这些。保存档案时页面会明确提示这几项一律不存。示例里出现的「张三」「某某医院」只是占位写法，不是真实身份信息。

「脱敏」开关只做一件事：把姓名打码显示，例如三个字的名字会显示成"张\*\*"这种形式；其余内容——日期、项目、数值、单位、参考区间、医院名——都保持原样，不会顺手改成空白。也就是说，它是**显示层**的处理，方便您把材料转给别人时少露一点身份信息，并不等于把报告里的其他内容加密或抹掉。打印前请按第四节第 4 条确认开关状态；给医生看时通常关闭，对外转发时再打开。

## 七、三条明确的"不做"

1. **不写诊断结论**：卡片只陈述报告里的数值、日期、出处和判定，不会替医生判断"是不是某种病、到了哪一期"。看到「▲ 高」「▽ 低」这类箭头或标着危急的提示，只是说明结果偏离参考区间，含义要由医生结合病史解释。
2. **不给治疗建议**：不会写该不该用药、要不要住院、何时复查等医嘱。第 1 页的「家属三问」是留给您自己填写想问医生的问题，没填就留白，可打印后手写；系统不会代填建议。
3. **不提供删除报告**：如第五节所说，没有删除入口。资料缺了会如实写「未录入 / 待核」，不会用猜测补齐，也不会因为看着"没用"就自动清掉某份报告。

如果某处显示与原件不一致，请以原件为准，按第五节的「修正数值」整行核对，或直接把原件给医生看。资料卡是帮您把资料摆整齐的工具，最终解释和决定都在医生那里。
