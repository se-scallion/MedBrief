## 1. A 线：模块①「危险分层可判断视图」（容器规格）

### 1.1 版式：在现有 4 格**下方**新增 6 格，**3 列 × 2 行**

```css
.risk-grid { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 4px 8px; margin: 3px 0 3px; }
.risk-cell { border: 1px solid #d1d5db; border-left: 3px solid #111; border-radius: 2px; padding: 3px 5px; }
.risk-t { font-size: 9px; font-weight: 700; color: #111; margin-bottom: 2px; }   /* 复用 .sb-t 口径 */
.risk-v { font-size: 9px; line-height: 1.35; color: #1f2937; }
.risk-src { font-size: 8px; color: #6b7280; }                                    /* 出处，复用 .kc-src 口径 */
```

| 量 | 值 | 算法 |
|---|---|---|
| 列数 | **3**（`1fr 1fr 1fr`） | 6 格排 2 行，比 2 列省 1 行高 |
| 列间距 / 行间距 | **8px / 4px** | 4px 半格基线 |
| 每格宽 | **236.6px** | (725.7 − 8×2) / 3 |
| 每格最小高 | **44px** | 标题 9px(≈13) + 至多 3 行值(≈12.2×3) + padding 6 |
| 6 格总高预算 | **≤ 96px**（含行距） | 2×44 + 4 + 边距 ⇒ **必须在第 1 页预算内**（见 1.4） |
| 字号 | 标题 9 / 值 9 / 出处 8 | 与既有 `.sb-*` 同口径，**不新造字号** |

**6 格的标题文字（内容待审核确认后填，此处只预留容器）**：
`① 诊断与分型` ／ `② 分子与基因` ／ `③ 分期/危险度（原文）` ／ `④ 危急值命中（带日期）` ／ `⑤ 初诊基线` ／ `⑥ 治疗反应/缓解状态`
> ⚠️ 这 6 个标题是**容器名**，实际显示哪些项、取哪些字段由审核结论填入；任何一项都**只摆原始值 + 出处**，不写"高/中/低危"结论（计划 R4）。

### 1.2 空值两态（黑白打印可辨，不靠颜色）

| 态 | 含义 | 样式（**必须两种都在判据里各出现一次**） |
|---|---|---|
| **待核** | 有字段、值为空 | `border: 1px dashed #6b7280`、`padding: 0 3px`、`border-radius: 2px`、`font-size: 8.5px`、文字 **`待核`** |
| **未查** | 库里没有该项 | `border: 1px dotted #6b7280`、其余同上、文字 **`未查`** |

```css
.risk-todo { display: inline-block; border: 1px dashed #6b7280; border-radius: 2px; padding: 0 3px; font-size: 8.5px; color: #374151; }
.risk-miss { display: inline-block; border: 1px dotted #6b7280; border-radius: 2px; padding: 0 3px; font-size: 8.5px; color: #374151; }
```
- **不许**用灰底/浅红底表示缺值（黑白打印会成脏块、且色差不可辨）；**虚线 vs 点线 + 文字本身**是唯一区分手段。
- 缺值**不许**留空白（医生会误读为"正常/没异常"）——这是既有红线「没查 ≠ 正常」的版面落实。

### 1.3 危急/异常标记（黑白友好）

- 复用既有 `.crit-tag`（黑底白字 8.5px·700）标 `危急`；
- 单格内至多 1 个标记，放在标题右侧 `margin-left: 4px`；
- **不加红/橙底**：打印不可辨，且会把"单次低谷"读成"长期高危"（计划 F4）。

### 1.4 版面预算红线（这条会跟趋势区抢页，必须先钉）

- 模块①总高（旧 4 格 + 新 6 格）**≤ 210px**；
- **第 1 页剩余可用高 ≥ 0**：`.page1` 的 `scrollHeight ≤ 1055px`（判据 R2）；
- 若将来审核结论要求更多项 ⇒ **先找我改规格**（可能要把 6 格改 3 列×3 行或移到页 2），**不许实现方自行加行**。

## 2. B 线：打印「自定义附页」勾选 UI

### 2.1 入口与控件

| 项 | 规格 |
|---|---|
| 位置 | 卡片页工具栏，「打印预览 / 存 PDF」**左侧**，间距 **8px**（`CardPage.jsx:230` 那个主按钮旁） |
| 控件 | antd `Button`（default、高 32）+ `Popover`（`trigger="click"`）+ 列表用 `Checkbox` |
| 按钮文案 | 未选：**`附页`**；已选 N 份：**`附页（N）`**（全角括号，与项目其它计数一致） |
| 按钮图标 | 内联 SVG（项目惯例，`@ant-design/icons` 未装），14px·`currentColor` |
| Popover 宽 | `≥768px`：**320px**；`≤575px`：`min(320px, 100vw − 32px)` |
| 列表项高 | **32px**（Checkbox 16 + 间距 8 + 文案行） |
| 列表行结构 | `[Checkbox 16] 8 [报告名 flex:1 nowrap ellipsis] 8 [日期 11px #8c8c8c] 8 [类型 Tag 20]` |
| 列表内滚 | `max-height: 320px; overflow-y: auto`（超过即滚，不撑高页面） |
| 搜索框 | 报告 **> 8 份**时显示 antd `Input`（`size="small"`、高 24、placeholder `搜索报告`），8 份以内不显示 |
| 空态 | `Empty` 文案 **`还没有可附的报告`** |
| 上限 | 已选 **≤ 10 份**；第 11 次勾选 `message.info('一次最多附 10 份报告')` 且不勾上（防打印爆页） |
| Popover 底部 | 一行 **12px `#8c8c8c`**：`附页按原件原样附在 3 页之后，不改写内容` |

### 2.2 页数文案规则（替换写死的「3 页 A4」）

| 状态 | 弹窗标题文案 |
|---|---|
| 未勾附页 | **`打印预览（3 页 A4）`**（与今天完全一致 ⇒ 默认行为零变化） |
| 勾 N 份、页数可取 | **`打印预览（3 + M 页 A4）`**，`M` = 附页总页数（图片/单页 PDF 记 1 页；多页 PDF 取实际页数） |
| 勾 N 份、页数取不到 | **`打印预览（3 + N 份附页）`**（不写页数，**不许编造**页数） |

- 同一行右侧保留既有 `已脱敏/未脱敏` Tag 与 `报告 N 份 · 指标 M 项` 文本，**不新增第三段长文本**（窄屏会换行）。

> **开工前提（更正）**：我在交付说明里写过「B 线不依赖审核、现在就能做」—— **这句撤回**。B 线是否放行属**分段放行判断**，按 `plan-review` §8.3 只能由**独立审核者**（代诊-报告 r1）判，**规格方无权批**。规格只提供版面数值，放行由审核者给。

### 2.3 窄屏（`≤575px`）

- 工具栏按钮与主按钮**同一行不换行**：两者 `flex: 1 1 0`、`min-width: 0`、`white-space: nowrap`；
- Popover 宽度 `calc(100vw − 32px)`、左右各留 **16px**；
- 列表项高仍 **32px**（不再加大，避免一屏只见 8 条）。

## 3. 判据口径（**门禁文件尚未存在**；由实现方编码时创建：`tests/verify-card-risk-ui.mjs`，`npm run test:card-risk-ui`）

> 前置：渲染 `renderHtml(card)`（含 6 格样例）到 headless Chromium，视口宽 900（A4 内容宽按 725.7 固定容器）；另渲染 `CardPage` 交互件用 Playwright 直驱。
> 三档退出码沿用项目口径：`failed ? 1 : (na > 0 ? 2 : 0)`；**禁止 `na()` 兜底夹具不足**。

| # | 判据 | 量测式 | 期望 |
|---|---|---|---|
| **R1** | 危险格 **3 列等宽** | `getComputedStyle('.risk-grid').gridTemplateColumns` 拆出 **3** 条；或按不同 x 起点数 = 3；两条轨道宽差 ≤1px | 3 列，格宽 **236.6 ±1** |
| **R2** | **第 1 页不溢出** | `.page1` 的 `scrollHeight` 与 `getBoundingClientRect().height` 都不超过 **1055px**；且 `.page2` 的 `break-before` 仍存在（未被挤走） | 全真 |
| **R3** | 空值两态样式可辨 | 至少各取到一个 `.risk-todo` 与 `.risk-miss`；`getComputedStyle(el).borderTopStyle` 分别 === **`dashed`** / **`dotted`**；文本 === `待核` / `未查` | 全真 |
| **R4** | 黑白可辨（不靠颜色） | 危急标记 `.crit-tag` 的 `background-color` = `rgb(17, 17, 17)` 且 `color` = `rgb(255, 255, 255)`；`.risk-todo/.risk-miss` 的 `background-color` 为 `transparent`（**不许灰底**） | 全真 |
| **R5** | 附页按钮与文案 | 勾 0：按钮文本 === `附页`；勾 3：=== `附页（3）`；第 11 次勾选后仍 === `附页（10）` 且出现提示文案 | 全真 |
| **R6** | Popover 尺寸 | `≥768`：宽 **320 ±1**；`≤575`（375 视口）：宽 **343 ±1**（= 375−32）；列表 `scrollHeight > clientHeight` 时 `overflow-y` ∈ {auto, scroll} | 全真 |
| **R7** | 页数文案 | 未勾 → 标题含 `（3 页 A4）`；勾 2 份且页数已知 → 含 `（3 + M 页 A4）`；页数未知 → 含 `（3 + 2 份附页）` 且**不含** `页 A4` | 全真 |
| **R8** | 默认行为零变化 | 未勾附页时 `renderHtml()` 输出与改造前**逐字一致**（与 fixture 比对），`/api/intake/card` 无参数时 `html` 长度差 = 0 | 真 |
| **R9** | 窄屏不换行 | 375 视口下工具栏两按钮 `scrollWidth <= clientWidth + 1`、`whiteSpace === 'nowrap'`、同行（`y` 差 ≤1） | 真 |
