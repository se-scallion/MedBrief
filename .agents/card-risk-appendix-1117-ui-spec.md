## 1. A 线：模块①「危险分层可判断视图」（容器规格）

### 1.1 版式：在现有 4 格**下方**新增 6 格，**3 列 × 2 行**

```css
.risk-grid { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 4px 8px; margin: 3px 0 3px; }
.risk-cell { border: 1px solid #d1d5db; border-left: 3px solid #111; border-radius: 2px; padding: 3px 5px; }
.risk-t { font-size: 9px; font-weight: 700; color: #111; margin-bottom: 2px; }   /* 复用 .sb-t 口径 */
.risk-v { font-size: 9px; line-height: 1.35; color: #1f2937; }
.risk-src { font-size: 8px; color: #6b7280; }                                    /* 出处，复用 .kc-src 口径 */
```

| 量 | 值 | 算法 |
|---|---|---|
| 列数 | **3**（`1fr 1fr 1fr`） | 6 格排 2 行，比 2 列省 1 行高 |
| 列间距 / 行间距 | **8px / 4px** | 4px 半格基线 |
| 每格宽 | **236.6px** | (725.7 − 8×2) / 3 |
| 每格最小高 | **44px** | 标题 9px(≈13) + 至多 3 行值(≈12.2×3) + padding 6 |
| 6 格总高预算 | **≤ 96px**（含行距） | 2×44 + 4 + 边距 ⇒ **必须在第 1 页预算内**（见 1.4） |
| ＋说明行（§1.3b） | **16px**（一行）/ **28px**（两行） | 说明行**不进格**，不占列宽、不改格数 |
| **模块①新增部分合计** | **≤ 112px**（单行）／ **≤ 124px**（两行） | 96+16 / 96+28；仍 ≤ 210 总预算 |
| 字号 | 标题 9 / 值 9 / 出处 8 | 与既有 `.sb-*` 同口径，**不新造字号** |

**6 格的标题文字（内容待审核确认后填，此处只预留容器）**：
`① 诊断与分型` ／ `② 分子与基因` ／ `③ 分期/分组（原文）` ／ `④ 危急值命中（带日期）` ／ `⑤ 初诊基线` ／ `⑥ 治疗反应/缓解状态`
> ⚠️ 这 6 个标题是**容器名**，实际显示哪些项、取哪些字段由审核结论填入；任何一项都**只摆原始值 + 出处**，不写"高/中/低危"结论（计划 R4）。

### 1.2 空值两态（黑白打印可辨，不靠颜色）

| 态 | 含义 | 样式（**必须两种都在判据里各出现一次**） |
|---|---|---|
| **待核** | 有字段、值为空 | `border: 1px dashed #6b7280`、`padding: 0 3px`、`border-radius: 2px`、`font-size: 8.5px`、文字 **`待核`** |
| **未查** | 库里没有该项 | `border: 1px dotted #6b7280`、其余同上、文字 **`未查`** |

```css
.risk-todo { display: inline-block; border: 1px dashed #6b7280; border-radius: 2px; padding: 0 3px; font-size: 8.5px; color: #374151; }
.risk-miss { display: inline-block; border: 1px dotted #6b7280; border-radius: 2px; padding: 0 3px; font-size: 8.5px; color: #374151; }
```
- **不许**用灰底/浅红底表示缺值（黑白打印会成脏块、且色差不可辨）；**虚线 vs 点线 + 文字本身**是唯一区分手段。
- 缺值**不许**留空白（医生会误读为"正常/没异常"）——这是既有红线「没查 ≠ 正常」的版面落实。

### 1.3 危急/异常标记（黑白友好）

- 复用既有 `.crit-tag`（黑底白字 8.5px·700）标 `危急`；
- 单格内至多 1 个标记，放在标题右侧 `margin-left: 4px`；
- **不加红/橙底**：打印不可辨，且会把"单次低谷"读成"长期高危"（计划 F4）。

### 1.3b 区块底说明行（原 ⑦「缺口清单」，**不进格**）

- 位置：`.risk-grid` **下方**，`margin-top: 2px`，占满块宽（不放进任何 `.risk-cell`）。
- 字号 **9px / 行高 1.35**、颜色 `#6b7280`、**不加粗、不加边框**；`white-space: normal`（可换行，最长 2 行）。
  ```css
  .risk-note { font-size: 9px; line-height: 1.35; color: #6b7280; margin-top: 2px; }
  ```
- 文案（**内容待审核确认后填**）：形如 `缺口：{字段名} 待核 / 未查 …；以上为原始值与出处，不等同于危险分组结论；分组由医生结合指南判断`。

**为什么不是计划侧写的 12px（我改判，理由可核）**：本卡字号层级是 章标题 `h2` **12px**、模块①格标题 **9px**、正文 **9px**、出处 **8px**。说明行用 **12px 就与章标题同级**，等于把「附注」抬成「段落标题」，破坏层级（团队规范「同一层级不得出现两个字号」）。
- 采 **9px**（与 `.sb-l` 同口径）：行高 ≈12.2px，仍是「正文级附注」，不与 `h2` 抢层级；
- 若审核/主理人坚持 12px，必须**同时**满足：不加粗、颜色 `#6b7280`、且**移到块外**，否则一律按 9px。

### 1.4 版面预算红线（这条会跟趋势区抢页，必须先钉）

- 模块①总高（旧 4 格 + 新 6 格）**≤ 210px**；
- **第 1 页剩余可用高 ≥ 0**：`.page1` 的 `scrollHeight ≤ 1055px`（判据 R2）；
- 若将来审核结论要求更多项 ⇒ **先找我改规格**（可能要把 6 格改 3 列×3 行或移到页 2），**不许实现方自行加行**。

```css
.ph-src  { font-size: 8px;   color: #6b7280; }                          /* 日期/方法/天数，允许行内混排 */
.ph-gap  { font-size: 8px;   color: #111827; font-weight: 700; }        /* 「相隔 73 天」加粗提一级（黑白可辨） */
```

**两行结构（固定两行，不做单行挤压）**：

| 行 | 内容模板 | 说明 |
|---|---|---|
| 行 1 | `BCR::ABL1（P190 型）<b>阳性</b>` ＋ `2026-07-18`（8px 灰） | 定性时点；值加粗，日期细灰（与既有 `初诊 xxx（07-18）` 同形） |
| 行 2 | `→` ＋ `P190/ABL <b>0%</b>` ＋ `2026-09-29 · RQ-PCR`（8px 灰） ＋ `｜` ＋ **`相隔 73 天`**（8px·700·`#111827`） | 定量时点 + 方法出处 + 派生天数 |

**日期写法（与卡内既有口径一致，且防跨年歧义）**：
- **同年**：用短格式 **`07-18` / `09-29`**（既有 `.sb-l` 的「初诊 … （07-18）」就是这个口径，混用会不一致）；
- **跨年**：两处都写**完整 `YYYY-MM-DD`**；
- **天数**：`相隔 N 天`，`N = round(|t2 − t1| / 86400000)`；**N 由运行时算出**，代码里不许出现字面量 `73`。

尺寸预算：两行 ≈ **24.4px** + `margin-top 2px` ⇒ 格 1 增高 **≈26px**；**不影响列宽/格数**，但第 1 页要重新对预算（判据 M4）。

### 6.3 红线（只写原始值，不写结论）

- **禁止出现**：`转阴`、`阴转`、`分子学反应`、`MRR`、`CMR`、`完全缓解`、`缓解`、`良好`、`显著`、`有效`、`达标`、`优于`、`提示`。
- 允许：原始值（`阳性` / `0%`）、方法（`RQ-PCR`）、日期、`相隔 N 天`、`→`。
- 理由：用户明确保持"半覆盖"、不由我们定判断条件；写"归零/转阴"就是替医生下结论（计划 R4 同一条红线）。
