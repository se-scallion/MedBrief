# MedBrief · 挂号与问诊资料整理工作台

独立就医辅助系统，专为白血病与重大血液病患者设计。

## 核心功能

1. **真实号源与出诊监控（首选目标：北京朝阳医院 血液科 主鸿鹄 主任）**：
   - 实时穿透抓取首都医科大学附属北京朝阳医院官网（Index_1220.html）排班与停诊公告。
   - 官方放号规则（每日 07:00 准时放第 14 天号源）高精度毫秒级倒计时。
   - 放号前 5 分钟、1 分钟、10 秒 Web Audio API 蜂鸣声光预警。
   - 自动定时巡检（15s / 30s / 60s 轮询），停诊或出诊状态变更时自动报警。
2. **问诊病历资料整理 (.meddata 导出)**：
   - 一键录入化验关键指标（白细胞、血红蛋白、血小板、骨髓原始细胞等）。
   - 生成符合 MedData 标准的加密自校验交换包（`.meddata`，带 SHA-256 指纹），可直接导入 MedData 或供专家面诊审阅。
3. **预约与凭证管理**：
   - 支持本地就诊人档案管理与预约流水记录。
   - 官方认证挂号渠道（微信「北京朝阳医院患者服务」/「京通」/ 010-114）操作指引。

## 启动与运行

```bash
# 启动服务（独立端口 5174）
pnpm start # 或 node server.mjs

# 运行自动化端到端测试
pnpm test # 或 node tests/verify-e2e.mjs
```

服务访问地址：`http://localhost:5174`
